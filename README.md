# Student AI Helper

An AI-powered study assistant built using Flask and local LLMs.

## Features

- Subject selection
- English and Hindi support
- Dark mode
- Chat history
- Math rendering
- Local AI using LM Studio

## Tech Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- LM Studio
- Google Gemma 3n E4B

## Future Improvements

- Personalized study plans
- Weak topic detection
- Revision generator
